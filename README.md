# ATM-system
#### ATM-system — учебный банковский сервис, включающий работу с пользователями, счетами и транзакциями. Система поддерживает авторизацию через API Gateway, безопасное взаимодействие по ролям и хранение событий в отдельном сервисе через Kafka.

## Основной функционал
#### Управление пользователями (создание, поиск, фильтрация, добавление/удаление друзей).
#### Управление счетами (создание, просмотр, пополнение, снятие, переводы).
#### История операций по счетам.
#### Авторизация и аутентификация.
#### Асинхронное хранение событий через Kafka.


## Проект разделён на модули:

### Application
#### Бизнес-логика (пользователи, счета, транзакции).
#### Поддержка правил комиссий (0% самому себе, 3% другу, 10% остальным).

### Presentation
#### REST API для взаимодействия с системой.
#### Контроллеры и DTO.

### Infrastructure
#### Подключение к базе данных

### Gateway
#### API Gateway
#### Авторизация и аутентификация через JWT.
#### Роли:
#### Admin — управление пользователями и их счетами.
#### Client — работа со своими данными и переводами.

### Storage
#### Отдельный сервис для хранения событий о пользователях и счетах.
#### Получает сообщения из Kafka (client-topic, account-topic).
#### Сохраняет события в собственную базу данных.

## Используемые технологии
#### Java 23, Maven
#### Spring Boot, Spring Data JPA, Spring Security
#### PostgreSQL, Docker
#### Kafka для событийного взаимодействия
